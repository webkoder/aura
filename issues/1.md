# Blueprint: Setup Monorepo Completo (NestJS + Vue 3 + Prisma + JWT + Docker)

## Introduction
This document serves as a comprehensive guide for setting up a complete monorepo architecture using NestJS, Vue 3, Prisma, JWT, and Docker.

### Monorepo Structure
Here is the proposed structure for your monorepo:

```
/
├── packages/
│   ├── contracts/
│   ├── sdk/
│   └── shared/
├── apps/
│   ├── api/
│   └── web/
├── infra/
│   └── docker-compose.yml
├── docs/
└── .vscode/
    └── launch.json
```

#### c. Shared

### 3. Apps
#### a. API (NestJS)
- **AuthService Implementation**:
```ts
import { Injectable } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';

@Injectable()
export class AuthService {
  constructor(private jwtService: JwtService) {}

  async login(user: User) {
    const payload = { username: user.username, sub: user.userId };
    return {
      access_token: this.jwtService.sign(payload),
    };
  }
}
```
